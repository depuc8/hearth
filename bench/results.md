## Supplementary: ApacheBench

wrk was unavailable, so as a stand-in these numbers come from
`ab -k -c 64 -t 30` (keep-alive, 64 concurrent
connections, 30s per target). ab drives all connections from a *single*
thread, so it usually saturates before the server does: read these as
a lower bound, and don't compare them directly with wrk results.
